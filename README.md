# 📂 File Organizer Tool

A Python script that automatically organizes files in a folder 
by moving them into categorized subfolders.

---

## 🚀 What it does

- Scans a folder
- Detects file types by extension
- Moves files into folders like Images, Videos, Documents, etc.
- Handles unknown files in "Others" folder

---

## 📁 Categories Supported

| Category | Extensions |
|---|---|
| Images | .jpg, .jpeg, .png, .gif, .webp |
| Videos | .mp4, .mkv, .avi, .mov |
| Documents | .pdf, .docx, .txt, .pptx, .xlsx |
| Music | .mp3, .wav |
| Python Files | .py |
| Zip Files | .zip, .rar |

---

## ▶️ How to Run

1. Clone this repo
2. Open `file_organizer.py`
3. Run the script
4. Enter your folder path
5. Done! ✅

---
