


# 📂 File Organizer Tool

A Python script that automatically organizes files in a folder by moving them into categorized subfolders.

## What it does
- Scans a folder
- Detects file types by extension
- Moves files into categorized folders
- Unknown files go to "Others" folder

## Categories Supported
| Category | Extensions |
|---|---|
| Images | .jpg, .jpeg, .png, .gif, .webp |
| Videos | .mp4, .mkv, .avi, .mov |
| Documents | .pdf, .docx, .txt, .pptx, .xlsx |
| Music | .mp3, .wav |
| Python Files | .py |
| Zip Files | .zip, .rar |

## How to Run
```bash
python file_organizer.py
```
